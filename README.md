# Domain suggestion in the Wix ChatGPT plugin

Clickable concept of offering a custom domain right after a site is created in ChatGPT with the Wix app.
Two surfaces, one shared state: an inline domain card in the closing message and a browser-style address bar
in the "Wix site" side pane. Get → "Continue on Wix" → mock Wix checkout → Setting up → Connected.

Live: https://adamdisa.github.io/wix-chatgpt-domain-demo/

Single static file (`index.html`), no build. The site name, free address and preview come from a real run
on 2026-11-05; nothing is purchased and no price is shown. Use the top bar to switch concepts and variants,
open "Spec" for states, data, copy rules and open questions, or "Presentation mode" to hide the controls.
